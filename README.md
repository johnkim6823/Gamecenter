# 🎮 Game Center

웹 기반 게임 시뮬레이터 모음입니다. 별도 설치 없이 브라우저에서 바로 플레이할 수 있습니다.

## 게임 목록

### 🎱 로또 6/45 시뮬레이터

한국 로또 6/45를 시뮬레이션합니다.

**기능:**
- **자동**: 원하는 게임 수(최대 5게임)를 선택하면 번호 자동 생성
- **수동**: 1~45 중 6개 번호를 직접 선택
- **반자동**: 일부 번호를 선택하면 나머지를 자동으로 채움
- 실제 로또와 동일한 색상 체계 (1~10 노랑, 11~20 초록, 21~30 빨강, 31~40 회색, 41~45 파랑)
- 추첨 애니메이션 및 보너스 번호
- 1~5등 당첨 판정 및 상금 계산
- 투자 금액 대비 수익률 통계

### 🎫 티켓팅 시뮬레이터

인터파크, 티켓링크, 멜론티켓 스타일의 티켓 예매를 시뮬레이션합니다.

**플랫폼 선택:**
- **인터파크 티켓** - 보라색 테마
- **티켓링크** - 레드/블루 테마
- **멜론티켓** - 그린 테마

**공연장 (실제 공연장 기반 좌석 배치):**

|--------|-----------|

| KSPO DOME (올림픽체조경기장) | 15,000석 |
| 고척스카이돔 | 18,000석 |

| SK올림픽핸드볼경기장 | 5,000석 |

**티켓팅 플로우:**
1. 플랫폼 선택 (인터파크 / 티켓링크 / 멜론티켓)
2. 공연 선택 (8개 공연)
3. 날짜 및 회차 선택
4. 대기열 시뮬레이션 (접속자 순서 대기)
5. 공연장별 좌석 선택 (등급별 구역, 최대 4매)
6. 결제 (6가지 결제 수단 + CAPTCHA 인증)
7. 결과 (성공 80% / 실패 / 시간초과)

## 실행 방법

```bash
# 로컬에서 실행
# 아무 웹 서버로 index.html을 열면 됩니다

# 예시: Python
python -m http.server 8000

# 예시: Node.js
npx serve .
```

브라우저에서 `http://localhost:8000` 접속 후 플레이하세요.
